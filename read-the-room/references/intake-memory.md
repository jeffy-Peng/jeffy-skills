# 摄取协议：只有模糊记忆

这是最高频、也最容易做坏的一类输入。用户带着一句"我感觉他不太想合作"来，而手上什么都没有。

**核心原则：从模糊记忆里能可靠提取的是"结构"，不是"细节"。**

用户记不住对方说了什么字，但往往记得住：他关心的是价格还是时间、他提到了谁、他问了哪一类问题、当时谁在主导话题。结构信号在记忆里存活得最久，而它恰好比措辞更接近真实关切。

**绝对禁止：把用户的印象当成对方说过的话。** "他表示会考虑"不是 L1，是 L3。

## 一、先做一次具体性提取（不要跳过）

不要直接开始分析。先用下面这张顺序表把细节挖出来——每一项都尽量转成可观察的事实（L1/L2）：

| 挖什么 | 问法 |
|---|---|
| 时点 | 什么时候的事？大概是几周前还是几个月前？是第一次见面还是第几次？ |
| 时长与场合 | 聊了多久？在哪？还有谁在场？谁约的谁？ |
| 收尾 | 最后一句是谁说的？说的是什么？怎么散场的？ |
| 具体数字 | 谈过价格、工期、数量、时间点吗？任何一个数字都行 |
| 具体人名 | 他提到过谁？（老板、技术、财务、同事、其他供应商） |
| 他问了什么 | 他问了你哪些问题？哪个问题他问了不止一次？ |
| 你的动作 | 你给了他什么？报价、方案、样品、承诺、名片？ |
| 变化 | 他的态度过程中有变化吗？从哪一刻开始变的？ |
| 承诺 | 他答应过什么事吗？答应之后做到了吗？ |

**收尾问题是最高杠杆的一问。** 散场方式往往比过程更能说明结果：他送你到电梯口并约下次 = 强信号；他说"回头联系"然后没了 = 弱信号加一次未验证承诺。

## 二、六问具体化法（用户说"我不记得了"时用）

抽象印象无法分析，具体场景可以。把印象换成场景：

1. **换场景**："如果是你同事遇到这种情况，你会怎么描述对方？"
2. **换对比**："跟以前合作过的客户比，他更像哪一种？"
3. **换极端**："如果他其实很有兴趣，会有什么表现是你没看到的？"
4. **换身体**："当时你觉得放松还是紧张？哪里让你不舒服？"
5. **换时间**："如果你必须指出一个他态度变化的时间点，是哪个？"
6. **换角色**："如果你是他，你当时最需要跟谁说清楚什么？"

**记忆锚点技巧：** 让用户回忆**具体的一句话**（哪怕只有半句）、**一个动作**（递东西、看手机、皱眉、叫别人进来）、**一个场景细节**（桌上的东西、谁先走）。一个真实的细节比十个印象值钱，因为细节能锚住整段记忆的可靠性。

## 三、有效信号清单：变淡了但结构还在

信心不足时，逐项过下面这张表。**判定由你（AI）做，不由用户做**——详见本节末尾的告警。

- [ ] 他主动提过具体的**时间点**或**截止期限**
- [ ] 他提到过**具体的人**（要问谁、谁会用、谁有意见）
- [ ] 他问过**具体的数字**（价格、工期、数量、比例）
- [ ] 他提过**条件**（要我们做什么才继续）
- [ ] 他**主动联系过**你（哪怕只是转发一条消息）
- [ ] 他把你的材料**转给了别人**
- [ ] 他**重复问过**同一个问题
- [ ] 他给了你**下一步**（下次见面、发方案、见某人）
- [ ] 他在结束前**替你考虑过**（帮你修方案、提醒你注意事项）
- [ ] 他在你报价后**没有消失**，而是继续讨论细节

### 覆盖率门（不是自评打分）

**判定的执行者是 AI，不是用户。** 每项只有能落到**一句可引用的原话或一个可描述的动作**时才算成立；落不到就不算。逐项写出判定依据，再计数。

**覆盖率 = 成立项数 / 9**（分母固定，不随用户说了多少而变）。

| 覆盖率 | 允许的输出 |
|---|---|
| **< 2 项** | **禁止给动作**，只给一个探针 + "这一步之前不要投入" |
| **2–4 项** | 可做临时判断；**不得给决策卡**（见 [evidence-ladder.md](evidence-ladder.md) 的「弃权规则」） |
| **≥ 5 项** | 可给决策卡，但**必须在卡里逐项列出这 5 项各自的原文或动作** |

**告警一（偏差方向）：** 这套流程最危险的失效不是漏判，而是**越需要被拦住的人越容易勾满**——正着迷的用户会把礼貌读成兴趣（见 [evidence-ladder.md](evidence-ladder.md) 的「记忆污染条款」）。所以当成立项**集中在"承诺 / 条件 / 时间"这类容易被善意记忆美化的类别**时，先按"正着迷"档整体下调一档再输出。

**告警二（重复计分）：** 多项其实来自**同一次交流的同一句话**时，只算 1 项。用户把一件事说三遍，不等于三个证据。

**告警三：** 用户强烈坚持某个结论时，不要提高覆盖率，而要**降低它**——坚持本身是情绪信号，不是证据。

反向清单（同样重要）——出现这些，说明"感觉不错"很可能是错觉：

- [ ] 全程只有你在介绍，他只在点头
- [ ] 所有称赞都是笼统的，没有一处具体
- [ ] 问到价格或下一步时，话题被转开
- [ ] 他给的下一次接触没有时间
- [ ] 他一直在说"我们内部""再看看""有消息我通知你"
- [ ] 结束时是你主动收尾，他没有追加任何问题

## 四、按记忆类型定性

用户的记忆质量决定能用什么：

| 记忆类型 | 表现 | 可用性 |
|---|---|---|
| **场景型** | 能说出具体对话片段、动作、环境 | 可当 L2 使用（细节可能有小误差） |
| **关系型** | 记得"感觉合得来/不舒服"，记不住内容 | 只能用于判断关系温度，不能判断业务意向 |
| **结论型** | 只记得"我觉得他不想做" | 这是 L4。必须挖出它立在哪件事上，否则不参与判断 |
| **空缺型** | "记不清了，就是感觉不好" | 停下来，先谈记忆本身的来源：是不是别人的转述？是不是一次间接信号？ |

**结论型记忆要特别处理。** 用户带着一个已经形成的判断来，却说是来求分析——这时他的真实需求往往是**寻求确认**。

**不要问用户"你觉得这是不是同一件事"**（他会说是，因为他想让你认同他的结论）。**你自己数**：把他给的所有依据列成一列，标出每一条指向的是同一件事还是不同的事。若全部指向同一件事 → 直接说出来："你现在的三条依据其实是**一件事的三次复述**。"然后回到 L1。

另外，如果他给的每一条信息都指向同一个结论、且都来自同一件小事，明确告诉他这一轮不构成分析材料——**这时候正确的动作是补一次接触，不是继续推理。**

## 五、产出与交付降级

这类输入**不要输出满篇决策卡**。正确的交付是：

1. **一段 3–6 句的短判断**：卡点最可能在哪个环、置信度低、为什么。
2. **一个探针问题**：下一次接触时用哪一句话去补信息，以及这个答案会怎样改变结论。
3. **一句注意**：最可能犯的错是什么（多数情况是：把记忆里的印象当成了对方的表态，然后据此让利或退让）。

同时把这次提取出的 L1/L2 事实写进对象档案——模糊记忆的价值不在于这次能判断什么，而在于它开始积累成线。
