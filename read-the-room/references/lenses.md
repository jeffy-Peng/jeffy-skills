# 场景透镜

**一次只用一个透镜。** 混用会得出面面俱到但无法行动的结论。

透镜只替换"三环"的具体含义与追问重点，证据阶梯与判断门槛不变。

**选择规则：** 看这一局的核心风险在哪 —— 是钱的分配（谈判）、是权力与评价（向上）、是协同与功劳（平级）、是无关系基础（陌生）、还是关系已受损（修复）。

## 0. 通用三问（所有透镜共用）

| 环 | 问法 | 定错层的代价 |
|---|---|---|
| 想要什么 | 他要的结果是什么？他拿什么向上交差？ | 当成"不想要"→ 白让利 |
| 能不能定 | 决策权、预算权、时间权在谁手里？谁能否决？ | 当成"不想要"→ 纠缠错对象 |
| 怕什么 | 风险、责任、被比较、丢面子、被绑定 | 当成"不想要"→ 越加价值他越怕 |

**卡点 = 最低的那一环。** 定位卡点必须用排除法：能解释为什么不是另外两环，才算定位。

---

## 1. 谈判 / 成交（价格、条款、竞标、续约）

**核心事实：** 谈判桌上的话大部分不是信息，是姿态。所以逐字稿和聊天记录的解读权重要下调，行为证据权重要上调。

**三环改写成：**
- 想要什么 → 他要的是更低的价格，还是一个**能向上解释的结果**？这两者对策完全不同。
- 能不能定 → 他是决策者，还是**传话人**？传话人永远不能说"行"，只能回去汇报。
- 怕什么 → 他怕买贵被追责、怕选错被比较、怕绑定后没法换。**大多数"再谈谈价格"其实是"帮我解决内部解释问题"。**

**高频话术的读法与对策：**

| 他说 | 常见误读 | 更可能的处境 | 建议动作（不要直接让价） |
|---|---|---|---|
| "太贵了" | 预算不够 | 在测底线，或需要交代 | 问"跟什么比贵"：比竞品、比预算、还是比去年？三种答案三条路 |
| "再考虑一下" | 快成了 | 他缺一个能向上解释的理由，或缺权限 | 别催。问他"如果要往前走，还差哪一步" |
| "我们再看看别家" | 要跑 | 谈判手段，或他需要比价材料交差 | 帮他做比较材料（含你的强项），别贬低对手 |
| "能不能再降 X%" | 还能压 | 他要的是数字，还是"我争取到了"这个姿态 | 用非价格项换（账期、范围、案例、排期），让他有战功 |
| "你们的服务怎么样" | 关心质量 | 他在找免责证据 | 给可核验的第三方材料，别自夸 |
| "我尽量帮你推" | 他会推 | 他在提前卸责 | 问他"推的时候需要我提供什么"，把动作具体化 |

**探测性低威胁问法：** "如果要让上面好通过，是总价需要更低，还是同样的钱花在更看得见的地方更好？"

**禁忌：** 在没搞清决策权之前报价；主动降价换好感；连续追问；把对方当对手打；贬低竞品。

## 2. 向上沟通 / 要资源、要支持、要授权

**核心事实：** 上级的时间与风险承受度都比你想的稀缺。他关心的是"这件事会不会给我添麻烦"，而不是"这件事对不对"。

**三环改写成：**
- 想要什么 → 他要的是**他的**目标达成（业绩、上级评价、少出事），不是你的目标。
- 能不能定 → 他能不能定，还是也要向上要资源？他上面还有没有人卡着？
- 怕什么 → 怕背锅、怕被问细节答不上来、怕开了先例被其他人要。

**关键动作：**
- 把请求翻译成他的收益与风险，一句话说清"这对你意味着什么"。
- 给决策必要的选项与推荐（不要只带问题去），让他做选择题而不是问答题。
- **给他拒绝的台阶**，并留下退路：他拒绝时你能退到哪一步，提前想好。
- 重要请求先私下过一遍，别在公开场合逼他表态。

**常见误读：** 把"他没回复"读成"他不支持"。上级不回复通常是**在等你把方案说清楚到他能签字的程度**。

**时机：** 他刚被上面压过、刚出事、快考核时，成功率最低。看他的状态再开口，不是看你准备好了没有。

---

## 3. 平级协作 / 跨部门 / 争取配合

**核心事实：** 平级没有职权，只有交换。你要的不是"请他帮忙"，是**找到他能从这件事里得到什么**。

**三环改写成：**
- 想要什么 → 他的 KPI 是什么？帮他达成什么？他要的是省事、露脸、还是免责？
- 能不能定 → 他的资源是真的没有，还是不想给？（"我们没人力"通常是排序，不是事实）
- 怕什么 → 怕多做多错、怕被你抢功、怕被绑进一个他控制不了的坑。

**关键动作：**
- 明确给他"功劳归属"和"退出条件"——这两样比人情有用。
- 需求写成最小可交付，别一次要太多，先要一次小配合建立信用。
- 有共同上级的事，先私下对齐再上会，不要用会议施压。

**禁忌：** 用"公司要求""领导说了"压人（会被记恨且只生效一次）；在群里公开催；把对方的不配合解读为人品问题。

---

## 4. 陌生拜访 / 初次接触 / 冷启动

**核心事实：** 你唯一的任务是**换来下一次接触的具体承诺**，不是这一次成交。任何"这次没谈成就是失败"的心态都会让你当场用力过猛。

**三环改写成：**
- 想要什么 → 他为什么要在今天给你五分钟？你的东西和他当下哪件麻烦有关？
- 能不能定 → 他是不是决策者？大概率不是——目标是**问到该找谁**。
- 怕什么 → 怕被推销、怕浪费时间、怕你纠缠。

**关键动作：**
- 前 20 秒说清"我是谁、我为什么找你、我要占你多久"。
- 结束时必须拿到一个具体的东西：时间、人、材料要求、或明确的"不用了"。
- 明确拒绝比含糊客气有价值——**至少你知道该停手了**。

**常见误读：** 把对方的礼貌当成兴趣。初次接触里的"挺好的"几乎等于零信息。

**禁忌：** 通篇自我介绍；要求对方当场表态；把"回头联系"当成有效下一步。

---

## 5. 关系修复 / 处理不满与投诉

**核心事实：** 对方在情绪里时，任何解释都会被读成狡辩。顺序必须是**先处理情绪，再处理事实，最后处理方案**，不能跳步。

**三环改写成：**
- 想要什么 → 他要的是**被认真对待**，其次才是补偿。很多人最终要的是一句负责的话。
- 能不能定 → 你能承诺什么、不能承诺什么？**不要在情绪压力下超权承诺。**
- 怕什么 → 怕被敷衍、怕你是来推责的、怕事情再次发生。

**关键动作：**
- 先确认他的损失和感受（说清你理解了什么，不要用"我理解您的心情"这种空话）。
- 说清你能做什么、不能做什么，给时间点。
- 说清下次怎么防止；把责任归到机制而不是个人。
- 别在第一次沟通里谈条件交换，那会坐实"你是来推责的"。

**禁忌：** 立刻讲道理/摆证据；说"按规定"；把责任推给第三方或已离职的人；用"大家都这样"淡化。

## 选择速查

| 局面 | 透镜 | 最常被定错的环 |
|---|---|---|
| 报价后没动静、一直砍价 | 1 谈判 | 权限（当成意愿） |
| 老板不批、不给资源 | 2 向上 | 顾虑（当成不支持） |
| 兄弟部门不配合 | 3 平级 | 想要什么（没找到交换点） |
| 刚加上微信/第一次见 | 4 陌生 | 想要什么（没给对方的理由） |
| 客户发火、老客户流失 | 5 修复 | 顺序（先解释事实） |
| 说不上来，只知道"这个人挺难搞" | 先补证据 | 通常是把 L3 当成了事实 |
