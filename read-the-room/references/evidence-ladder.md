# 证据阶梯

判断的可靠性只取决于一件事：你说的话立在哪一级证据上。这份协议定义分级、易犯的错误、以及每级证据的门槛。

## 四级阶梯

| 级 | 名称 | 定义 | 例子 | 能用来做什么 |
|---|---|---|---|---|
| **L1** | 原话 / 可核验记录 | 逐字可复核的文本或音频证据 | 聊天记录原文、录音逐字稿、邮件、他签的字 | 支撑判断与行动 |
| **L2** | 可观察行为 | 不依赖解释就能确认的事实 | 已读未回、隔了几天回、主动多说了两句、带了同事来、把方案转给了别人、答应的事有没有做 | 支撑判断与行动（行为常比原话更真） |
| **L3** | 用户的感受与印象 | 主观体验，无外部对应物 | "我感觉他挺有兴趣"、"我觉得他有点敷衍"、"气氛挺好的" | **只能限定判断，不能支撑行动** |
| **L4** | 标签与推测 | 解释、归因、画像 | "他是 D 型人格"、"他就是想压价"、"他根本看不上我们" | **不得支撑任何行动建议**，只能作为待验证假设 |

**分栏纪律：** 记录时 L1/L2 与 L3/L4 必须物理分开写。写在同一段里，推测会伪装成事实。

## 两条反直觉条款

这三条是这份协议里最容易违反、又最影响判断质量的：

### 1. 笼统赞美是弱证据

"你们这个挺好的"、"有机会一定合作"、"做得不错" —— 这些几乎不携带信息。它们通常只说明对方不愿当场制造不愉快。

**强证据长这样：** 具体的数字、时间、人名、条件、下一步动作。

- 弱："这个方案我们很感兴趣。" → 可能是礼貌。
- 强："七月十五号之前能进场吗？我要跟王总报一下。" → 出现具体时间 + 具体人 + 具体动作，这是真实推进信号。

**推论：愿意挑剔的人通常比一味说好的人更接近成交。** 他花时间挑毛病，说明他在替自己找能用的理由；他一句意见都不提，往往是没打算用。

### 2. 沉默、延迟、改口：按需加载

这三类信号是 L2 事实，但极易被过度解读。它们的读法（含"能做的推断 / 不能做的推断 / 该怎么验证"三栏对照表）在 [signals.md](signals.md)。

**只在材料里有聊天记录、逐字稿、或用户描述"他不回我"时读那一份。** 材料是模糊记忆或只有几句话时不要读——读了只会诱导你对沉默做过度解读。

但有一条必须现在就记住：**沉默不是拒绝，也不是兴趣。** 需要解释它时，先问"他是不是答不了这句话"。

## 记忆污染条款（L3 专用）

用户在回忆时几乎无法避免地带有情绪。回忆质量高度依赖他当前的状态：

| 状态 | 典型失真 | 处理 |
|---|---|---|
| 正着迷 / 很兴奋 | 把礼貌读成兴趣，把"有机会"读成"有戏" | 强制清点对方是否给过任何具体条件；没有就下调 |
| 被拒受伤 / 受挫 | 把中性行为读成否定，把忙读成嫌弃 | 强制区分"他拒绝了这件事"和"他拒绝了我" |
| 焦虑（这个单子要完不成） | 放大每一个信号，过度解读 | 只保留 L1/L2，暂停解读 |
| 愤怒（刚被刁难） | 把对方全部行为归为恶意 | 先处理情绪，隔一轮再判断 |
| 疲惫 / 喝过酒 | 细节记错，顺序混乱 | 只采记忆结构（他关心什么），不采细节数字 |

**操作要求：** 在对象档案和决策卡里，凡引用 L3，必须同时写上当时的状态标签与一句限定——"该印象可能被当前情绪放大"。

区分"他不想要这件事"和"他不想要我"，是这里最实际的一次纠偏：前者要换方案或换时机，后者要修关系，两者动作完全相反。

## 判断门槛

不同强度的结论，需要不同强度的证据。达不到门槛就降级措辞，而不是硬下结论。

| 结论类型 | 最低门槛 | 达不到时降级为 |
|---|---|---|
| 事实判断（他说过/没说过什么） | 一条 L1，或两条独立 L2 | 不下结论，写"未确认" |
| 意向判断（他想不想推进） | 一条 L1 或 L2 行为证据 + 一条**独立语境**（见下方定义） | "暂定倾向" |
| 卡点判断（卡在哪一环） | 至少两条 L1/L2，且排除了另外两环 | "暂定倾向" + **只给一个探针**（见下方「弃权规则」；**不得给两个对应动作**，用户只会挑他想听的那条去做） |
| 权限判断（他能不能定） | L1（他自己说、或组织架构/流程事实） | "待确认"，并给探针问题 |
| 预测（他下一步会怎样） | 意向判断 + 同类历史行为（档案里有） | "如果…那么…"，写明触发信号与替代解释 |
| 人品 / 性格 / 意图归因 | **不设门槛，一律不输出** | 写成待验证假设或直接删除 |

**排除法要求：** 说"卡点在权限"时，必须能解释为什么不是"不想要"、也不是"怕"。三环里排除了两环才算定位，否则就是猜。

### "独立语境"的合法来源（这是最容易被做假的一环）

门槛表里要求的"独立语境解释"，只有两类合法来源：

1. **跨事件印证**——对方**自己在别的场合、别的话题**下说过或做过的事；
2. **组织事实与公开信息**——岗位职责、审批流程、公开披露、第三方的独立说法。

**不合法的：** 用户对这个人的评价（"他这人就是谨慎"）、用户的推测（"他大概是怕老板"）、用户对同一件事的第二次复述。这三种都是 L3/L4 换了件衣服，**不构成独立来源**。

拿不到合法来源 → 按门槛表降级，不要用"用户又说了一遍"来凑门槛。

## 弃权规则（三环分不开时怎么办）

当材料薄到无法区分"他不想要 / 他不能定 / 他怕"，**不要输出"两种可能并存"再各配一条动作**——用户一定会挑他想听的那条去做，于是这一步等于没做。

正确的输出是三种之一：

| 情况 | 正确输出 |
|---|---|
| 还能再拿到信息 | **只给一个探针** + 一句"这一步之前不要投入" |
| 拿不到更多信息、但事情还能等 | **暂缓**：写清"在确认 X 之前不做任何投入"，并给出确认 X 的那句话 |
| 拿不到更多信息、事情也等不了 | **按最坏情况处理**，并把"这是一次赌博"明说，不要伪装成判断 |

**判定标准（机械可查）：**

- 三环里能写出依据的 **< 2 环** → **禁止给行动建议**，只给探针或暂缓。
- 只有 **1 环**有 L1/L2 支撑 → 置信度上限为"低"，且不许出现让价、加投入、追加承诺类动作。
- 全部依据都来自同一次交流、同一个话题 → 视为只有一条证据，不因"他说了很多"而升级。

**为什么必须机械：** 这套东西唯一的信源是用户本人（见 SKILL.md「你没有独立信源」）。没有一条硬规则，判断强度会随用户的情绪自行膨胀——他越急，输出越像"已经看清了"。

## 置信度标定

用锚点取值，不凭感觉：

| 置信度 | 含义 | 判断语言 |
|---|---|---|
| **高** | 有多条独立 L1/L2 相互印证，且无反证 | "可以按这个行动" |
| **中** | 有一条 L1/L2 支持，存在合理解释的替代 | "按这个准备，同时留一条退路" |
| **低** | 主要靠 L3，或缺关键一环 | "先别据此投入，先问这一句" |

**每条承重判断必须写"反证条件"**：什么信息出现，我就该改口。写不出反证条件的判断，说明它不可证伪，本就不该写进来。

## 一个反面样例（供自查）

错误示范：

> 张总对方案很感兴趣，但他比较谨慎，属于典型的分析型人格，一直在压价。建议加大价值塑造力度，强化紧迫感。

问题：把 L3（"很感兴趣"）当事实；L4 人格标签（"分析型"）无证据；"压价"未区分是试探还是真实预算限制；建议直接跳到动作，跳过了三环定位；无置信度、无未知。

正确示范：

> 张总说了两件事（L1）："你们比 A 家贵 12%"（4/3 14:20）、"这个价格我报上去不好看"（4/3 14:31）。他从未提预算数字，也没说贵在哪一项。
> 卡点可能不在价格，在**他在内部需要解释**（"报上去不好看"是向上交差的顾虑，属"怕什么"环）。
> 置信度中。若他说的是真的比较结果，则卡点在"怕什么"；若是常用的开场压价，则卡点在"想要什么"。
> 探针：问他"如果要让上面好通过，是总价需要更低，还是钱花在更看得见的地方更好？"——这一问能分开两种可能。
