# 决策卡模板

> 复制到 `insight/<对象标识>/cards/<YYYY-MM-DD>-<事由>.md`。
> **顺序不可调换**：误读 → 判断 → 动作 → 话术 → 禁忌 → 未知。
> 分量随证据走：材料不足时只写 1、2、4，其余留空，不要为了填满而编。
