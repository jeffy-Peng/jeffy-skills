# 对象档案模板

> 复制到 `insight/<对象标识>/dossier.md`。这是**累积状态**，每次接触后更新，不要每次重建。
> 本文件分两级：**事实区（只追加，不许改）** 与 **视图区（每次重算，可整体改写）**。维护规则见 [../references/dossier-maintenance.md](../references/dossier-maintenance.md)。
> 对象标识不要用手机号、身份证、完整姓名+公司等可识别组合，用代号或"公司-姓氏"级别即可。

## 当前处境（他现在处在什么处境）—— 处境一变整体重算

**只能填下列取值，不得自造词。** 不确定就写 `未知`，并把它加进 3.4 探针队列——**处境特征是跨对象匹配的主键，自造词会让规律库空转或错配。**

```
决策链位置 = 拍板者 / 评估者 / 传话人 / 使用者 / 未知
有否决者   = 有(技术) / 有(财务) / 有(上级) / 无 / 未知
时间压力   = 我方 / 对方 / 双方 / 无 / 未知
组织环境   = 流程型 / 灵活型 / 未知
对上级暴露 = 强 / 中 / 弱 / 未知
```

| 日期 | 处境变化 | 重算了什么 |

|  |  |  |

> **档一（第 1–2 次接触）不建本区。** 但**档二对象的第 3 次接触结束时，无论是否继续跟，都要把这一行补全并保留在索引里**——规律库的样本来自所有走到档二的对象，不是只来自"活到第 5 次"的那些。少了这一步，规律库就只学到"长期关系线"，却被用来服务新客户。

# 二、预测链与规律（每次判断都要留下可检验的赌注）

## 2.1 下注与对答案

| 日期 | 观察 | 推断 | 我下的注 | 预测 | 实际结果 | **结果证据级别** | 结论 |
|---|---|---|---|---|---|---|---|
|  |  |  |  |  |  | L1/L2/L3 | 成立/部分/不成立/**未验证** |

> **只有 L1 或 L2 的实际结果才能写"成立/部分/不成立"。仅凭用户叙述（L3）一律写"未验证"，且不计入 `patterns.md` 的次数与 `calibration.md` 的统计。** 未验证仍可进 1.3 淘汰区，但必须标注"未验证"。详见 [../references/dossier-maintenance.md](../references/dossier-maintenance.md) 第四节「闭合点的证据级别」。
>
> **不成立的必须进 1.3 淘汰区**，并写清被哪条证据推翻。没有闭环的档案只是聊天记录的高级版。

## 2.2 已晋升的规律（送进 `insight/patterns.md`）

| 规律 | 晋升日期 | 依据（须写清处境特征与结果级别） |
|---|---|---|
|  |  |  |

> 晋升门槛（严格版）：同一模式在本对象出现 **3 次** → 可预测；**在 3 个不同对象**身上复现（处境特征逐字相同、且各有 L1/L2 结果）→ 才可写进 `patterns.md`。
> **来源只到 L3（用户回忆）的，一律停在"未验证"，不计次数、不许晋升。** 详见 [../references/dossier-maintenance.md](../references/dossier-maintenance.md) 第四节。

# 附：索引行模板

> 每份档案建好或更新后，同步在 `insight/index.md` 维护一行。
> **索引是最小可用状态**：跨会话时先扫它，再进具体档案。关闭满 6 个月的移到 `insight/_archive/`。

| 对象标识 | 别名 | 关系类型 | 最近接触 | 档案状态 | 档位 | 处境特征（三项简写） | 一句话卡点 | 下次动作 |
|---|---|---|---|---|---|---|---|---|
|  |  |  |  | 活跃/待复核/休眠/关闭 | 档一/二/三 | 决策链=传话人·否决者=有(技术)·压力=无 |  |  |

> 对象标识创建后不再改名；同一人的其他身份写进"别名"列，不要新建档案。
> **处境特征这一列是规律库的原料**：档二对象结束第 3 次接触时务必补上，即使这条线不跟了。
> **档一对象在索引行下方直接追加流水行**（见 [../references/dossier-maintenance.md](../references/dossier-maintenance.md) 的「档一的一行流水」），不必另建 `dossier.md`。
