# 跨对象记忆模板（规律库 + 校准账本）

> 这两份文件是**档三**才启用的：完成 5 次接触，或用户明确说要长期跟。
> 不到档位不要建。空模板不会让你更准，只会让你不打开它。
> 它们是"第 10 个客户为什么比第 1 个准"的全部答案——单份档案做不到这件事。
>
> **统计口径铁律：** 只有**结果证据级别为 L1/L2** 的预测才计入本文件的任何数字。来源是用户回忆（L3）的一律记"未验证"并排除在外——否则这份账本记录的只是用户自己想让你看到的东西。

# 一、`insight/patterns.md` 规律库

## 1.1 跨对象规律

> 晋升门槛：同一现象在**3 个不同对象**身上复现，且这 3 个对象的处境特征**逐字相同**、各有 L1/L2 级别的结果。
> **2 个对象不够**——两次巧合的概率太高，而规律会被用户当成权威使用。结果只有 L3（用户回忆）的，一律记"未验证"，不计次数。
> **每条必须带适用处境与失效条件**，否则它会变成偏见的放大器。

| # | 规律 | 适用处境 | 失效条件 | 验证来源 | 次数 |
|---|---|---|---|---|---|
| 1 | 传话人 + 无时间压力 + 有技术否决者 → 不会主动推进，沉默不等于拒绝 | 决策链=传话人 / 压力=无 / 否决者=有 | 他主动引入技术方（进入评估，性质改变） | 科技公司-刘、制造-B集团-陈 | 2 |

**处境匹配顺序（冷启动时从上到下比，优先级递减）：**

1. 决策链位置（拍板者 / 评估者 / 传话人 / 使用者）
2. 有没有否决者
3. 时间压力在哪一边
4. 组织环境（流程型 / 灵活型）
5. 他对上级的暴露程度

**不要按性格或行业匹配。** "他也挺谨慎的"不可迁移；"他也是传话人、上面有技术否决者、自己不着急"才可迁移。

**⚠️ 冷启动限制（必须遵守，否则这一层会退化成偏见）：**

处境特征里的**前两项（决策链位置、有无否决者）在冷启动时通常正是未知的**——它们本来就是探针要去问的东西。所以：

1. **"已知"必须过证据级别。** 某个取值只有在档案里能追到一条 **L1/L2**（对方原话、组织公开事实、可观察行为）时才算已知；**来源是探针答案、且只有用户复述的，记为"未知"**，只能用来生成下一个探针。问过了 ≠ 验证过了。
2. **前 3 项（决策链位置 / 有无否决者 / 时间压力）必须全部有取值，且其中至少 2 项与规律的目标对象逐字相同，才允许套用规律。** 任何一项为"未知"，或只有 1 项对上 → **不许匹配**。只对上"决策链位置"一项就套用规律，等同按性格匹配。
3. 匹配成功后，规律只用来**生成探针和假设**（"这类人通常不会主动推进"），**不许直接用来下结论、决定投入或让价**。可检查标准：输出里有没有出现以规律为依据的动作。
4. 对象处境变化时（换人、进流程、出现否决者），立刻重新匹配，旧规律作废。

**宁可不用规律，也不要错配。** 一个错配的规律比没有规律危险得多，因为它带着"已验证"的可信度，用户不会怀疑它。

# 二、`insight/calibration.md` 校准账本

> 统计的不是客户，是**用户自己**。这是最可能让他惊讶的一层。
> **口径要诚实：样本少于 5 次不下结论，只写"样本不足"。** 假精确的百分比比不给更糟。

| 处境特征 | 预测次数 | 成立 | 部分成立 | 不成立 | **未验证** | 一致率 | 结论 |

| 决策链=拍板者 |  |  |  |  |  |  |  |
| 时间压力=对方 |  |  |  |  |  |  |  |
| 组织环境=流程型 |  |  |  |  |  |  |  |

**表头写"一致率"而不是"准确率"，这不是修辞：** 出题的人和判卷的人是同一个（都是用户的叙述），所以它衡量的是**你的判断与他的行为是否对得上**，不是你读人准不准。永远不要把这张表说成"读人准确率"。

**「未验证」列必须保留并单独统计。** 如果未验证的比例很高（比如超过一半），说明真正的问题是**你没有可观察的反馈渠道**，而不是你判断得准——这种情况下正确动作是设计能产生可观察反应的动作，而不是继续攒数字。

**样本现实性（先算这笔账）：** 只有 `预测次数 ≥ 5` 的行才能下结论，而表里有 4 行——**要读出任何一行，至少需要 20 次带 L1/L2 结果的预测**。在此之前本表只填数、不解读，也不要在建议里引用它。**一个格子只有 2–3 次时，那不是规律，是噪音。**

**读法：** 找出一致率明显偏低的那一行——那是用户最该换默认假设的处境。见 [../references/dossier-maintenance.md](../references/dossier-maintenance.md) 的「校准账本层」。
