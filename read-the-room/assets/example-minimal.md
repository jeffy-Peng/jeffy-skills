# 最小样例（30 秒读完）

这是日常单次咨询那一档的完整交付。**从头到尾只有这么长。**

用它判断一件事：这个 skill 的味道对不对。如果它太长，就该更短。

---

## 用户输入

> 昨天跟一个客户吃饭，聊了两小时。他人挺好的，也说了不少他们公司的困难。临走他说"你们这个我再看看，有消息联系你"。
> 我总觉得他是在客气。要不要再推一下？

## 交付

**先说你最可能想错的地方：** "他人挺好的、说了不少困难"——这两件事都不构成采购意向。他整晚讲的是**他自己的处境**，不是你的方案；而"有消息联系你"是没有时间、没有动作的软收尾。所以你觉得"他在客气"，这个直觉大概率是对的。

但要小心另一半：**"他在客气"不等于"他没需求"。** 他花两小时讲困难，说明困难是真的；真正没影的是**推进的路径**——你从头到尾没问出一件具体的事。

**判断：** 卡点在「想要什么」和「能不能定」之间，目前分不开。置信度低。
依据：只有一条 L2（他主动讲了自己的困难）+ 一句 L1（"有消息联系你"，无时间无人名）。
反证条件：如果他其实提过具体的部门、预算周期或评估流程，那卡点就转向「怕什么」。

**下一步不是再推一下，是换一句话问。** 现在推等于重复上次那句他无法回答的话。

**可以这么说（发消息，不要打电话）：**

> "王总，昨天您提到 XX 那块挺棘手的，我记着了。我想问一句：这类事在你们那边，一般是您这边看好了就能定，还是要走一个流程？我心里有个数，以后给您的东西能更对得上。"

- 作用：把"您考虑得怎么样"换成"流程是什么"。**不要求表态，只要求信息。**
- 他答"我能定" → 给方案；**报价节奏放在这一步之后**——本 Skill 禁止在探清决策权之前给具体价（见 `references/compose.md` 禁忌表）。
- 他答"要走流程" → 追问一句"那一般看哪些点？"——这就是你的评估标准。
- 最坏情况：他敷衍。那说明这件事在他那儿优先级确实不高，**该降级投入，不要加码。**

**这轮不要做的三件事：**

| 不要 | 为什么 |
|---|---|
| 不要发"您考虑得怎么样" | 他答不了，只会把沉默加深 |
| 不要现在让价或加送东西 | 卡点不是价格，空让价会让他怀疑方案本身有问题 |
| 不要因为"感觉他客气"就判定没戏 | 你缺的是信息，不是结论；先花一句话把信息补上 |

**这次不落盘**——单次咨询，没有跨轮需要，建档案是负担。

---

## 这段交付里体现的全部设计

对照着看，三句话就够：

1. **第一段在拆 L1/L2 与 L3/L4**——"人挺好"是印象，不算证据。
2. **第二段在做三环定位**，并诚实地说"现在还分不开"，而不是假装定位成功。
3. **结尾给的是探针，不是结论**——一句问流程的话，外加它三种答案分别意味着什么。
