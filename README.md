# jeffy-skills

我的个人 Agent Skills 仓库。

## Skills

| Skill | 用途 |
|---|---|
| [3d-deep-research](./3d-deep-research/) | 用可追溯证据链完成深度研究和报告交付 |
| [workplace-message-writer](./workplace-message-writer/) | 起草或润色自然、直接、行动导向的职场消息和邮件 |

## 安装

安装 3D Deep Research：

```bash
npx skills add Arslan-jh/jeffy-skills --skill 3d-deep-research
```

安装职场消息助手：

```bash
npx skills add Arslan-jh/jeffy-skills --skill workplace-message-writer
```

如需全局安装，在命令末尾加 `-g`。
