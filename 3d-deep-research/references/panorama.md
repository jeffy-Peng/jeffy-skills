# 全景图

XYZ 分析表除了写成正文，还可以生成一张可交互的立体全景图，与报告一起交付。图上每个转折是横轴上的一点，因素按推动与制约分在纵轴两侧，影响挂在竖轴的三挡高度上。

四个视角各回答一个问题，图上不必重复文字说明。

| 视角 | 只看 | 回答什么 |
|---|---|---|
| 等轴 | 全部图层 | 三根轴怎么对应，结构长什么样 |
| 因素平面 | Y 因素 | 谁在什么时候推、挡，多强 |
| 影响剖面 | Z 影响 | 每个节点的结果有多大 |
| 时间俯视 | X 时间 | 什么时候发生了什么 |

点击站点、连线或时间轴可以聚焦，右侧抽屉给出该转折或该因素的详情，包括来源编号、置信度和成立条件。筛选条可以只看核心、有翻转、推动或制约。

## 数据文件

一个研究项目一份 `xyz.json`，与报告同目录。字段和 XYZ 分析表一一对应。

```json
{
  "subject": "研究对象与年份区间",
  "question": "一句话研究问题",
  "cutoff": "2026-11-21",
  "xs": [
    {
      "id": "X1", "time": "2023 Q3", "short": "短语",
      "title": "转折的标题",
      "before": "之前是什么状态", "after": "之后变成什么",
      "result": "可观察的结果", "cites": ["S10"],
      "question": "仍待回答的问题"
    }
  ],
  "factors": [
    {
      "id": "F1", "name": "因素名", "core": true, "kind": "类型",
      "hex": "#5a6b7a", "thesis": "一句话说明它为什么重要",
      "segs": [
        { "x": "X1", "dir": 1, "w": 0.8, "scale": "长周期", "cite": "S05", "note": "依据" }
      ]
    }
  ],
  "impacts": [
    {
      "xid": "X1", "label": "结果短语", "tier": "弱",
      "c": "C01", "conf": "high", "attr": "强",
      "process": "作用过程", "condition": "成立条件",
      "path": ["第一步", "第二步", "结果"],
      "cites": ["S10"], "pending": false
    }
  ]
}
```

规则

- `xs[].id` 唯一，按时间排序；`factors[].id` 唯一
- `segs[].x` 必须落在 `xs` 里，同一因素可以缺某几个节点
- `dir` 取 1 推动、-1 制约、0 待查；`w` 取 0 到 1.2，越大离轴越远
- `scale` 取 短周期 / 中周期 / 长周期，画成 1 到 3 个点
- `impacts[].xid` 覆盖每个转折，`tier` 取 弱 / 中 / 强
- `cites` 用 S01 这种编号，`c` 用 C01 这种编号，与报告 A1、A2 账本同源
- 转折超过 8 个、因素超过 8 个时标签会变密，先考虑合并次要节点

## 生成

```bash
python [skill目录]/scripts/build_panorama.py xyz.json -o panorama.html
python [skill目录]/scripts/build_panorama.py xyz.json --check
```

命令读数据、校验、注入 `assets/panorama-template.html`，输出一个不依赖外部资源的 HTML。数据不合格时不生成文件，报错会指出具体是哪一行哪个字段。

校验拦住这几类问题。缺字段，id 重复，站位挂在不存在的转折上，方向或强度越界，影响记录没有覆盖全部转折，来源编号或判断编号格式不对，置信度不在 high / medium / low。

## 与报告一起交付

```
研究报告/
  xyz.json          数据源，报告与全景图共用
  report.md         报告源稿
  output.html       报告
  panorama.html     全景图
```

报告附录写一句「配套的可交互全景图是 panorama.html」。数据修订后重跑两条命令即可，图和正文同步更新，不用改模板。

交付前把两个 HTML 分别用浏览器打开。报告看正文、目录跳转、表格滚动和窄屏；全景图看四个视角能不能切换、标签有没有互相压住、点节点能不能出详情、窄屏下侧栏是否让位。
