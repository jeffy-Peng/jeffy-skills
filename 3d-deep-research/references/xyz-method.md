# X/Y/Z 三轴方法

## X 轴：时间线因果链

回答“它如何一步步走到今天”。选择 4-7 个真正改变资源、认知、路径或竞争位置的节点，不写完整年表。

每个节点回答：

1. 发生了什么；
2. 为什么在当时发生；
3. 它改变了什么；
4. 它通过什么机制导向下一节点；
5. 证据和替代解释是什么。

阶段按自然拐点划分。每个阶段只保留核心驱动力、主矛盾、关键决策和遗留问题。无法证明“因此”的地方写成时间相关或暂定解释，不伪装成因果。

## Y 轴：关键截面力场

从 X 轴选择 2-4 个如果省略就会显著削弱解释的截面。每个截面通常保留 3-5 股关键力量。

力量可来自竞品、资本、技术、市场、监管、人物/组织、舆论/社区、供应链/生态或宏观环境。不要逐类平铺；围绕一个主矛盾回答：

1. 谁主动塑造格局，谁被动响应；
2. 哪些力量互相强化或抵消；
3. 谁的选择空间最大，谁实际上没有选择；
4. 哪个被忽略变量改变了后续路径；
5. 这个截面如何改写 X 轴。

## Z 轴：内部机制

整篇只拆 2-5 个最有解释增量的机制。优先拆能解释关键路径选择、力场互动或表面叙事矛盾的力量。

每个机制回答：

1. 机制名称：用可验证的因果短语命名；
2. 内部结构：参与者、资源、利益和权力位置；
3. 行为动机：短期收益与长期目标；
4. 约束条件：技术、资金、组织、法律、声誉或路径依赖；
5. 互动关系：如何影响其他力量并接受反馈；
6. 替代解释：还有什么机制能解释同一现象；
7. 解释增量：拆解后比表面事实多理解了什么。

动机判断必须来自行为证据、当事方材料或利益结构。没有证据时写成推测，不做心理诊断。

## 三轴交汇

交汇不是摘要。至少形成一个新判断，并逐项说明：

| 维度 | 问题 |
|---|---|
| X | 哪些早期选择锁定或扩大了今天的优势与短板 |
| Y | 哪些力场加速、延缓或扭转了路径 |
| Z | 哪些机制解释了表面叙事解释不了的现象 |
| 交汇 | 三者共同导向什么机制判断 |
| 边界 | 判断最可能错在哪个前提 |

用以下格式记录交汇洞察：

```text
洞察：
X 轴依据：
Y 轴依据：
Z 轴依据：
替代解释：
置信度：
反证条件：
```

## 未来表达

先列 3-6 个驱动变量，并评估影响与不确定性。

- 一个变量组合明显主导：写基准路径、触发信号、受益/受损方、替代解释和反证条件。
- 两个变量同时高影响、高不确定：做 2×2 情景矩阵，并指出当前基准情景。
- 证据不足：只交付领先指标和验证计划。

不要用“增长、停滞、衰退”代替机制命名，也不要为了显得全面机械生成三套剧本。
