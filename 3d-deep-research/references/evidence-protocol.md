# 证据协议

核实关键事实，并使重要判断可以回到原文。检索贯穿定题、XYZ 分析、写作和回源审计。关键事实缺证据、来源存在冲突，或出现可能改变结论的解释时，提出具体问题，补查原文，并更新判断和账本。

## 从问题找材料

把影响结论的未知写成可查证的问题。确定要核实什么、谁可能留下原始记录、到哪里找。用对象、事件或指标和时间范围组合检索词。优先查会改变结论的问题，找到足以界定待比较状态或待解释变化的材料后进入分析。根据已查到的术语、口径和证据缺口调整下一轮检索。

对影响结论的问题，在已有研究记录或账本中留下实际查过的材料或主要检索词、所得结果及尚未解决的问题。涉及当前状态时，联网核对截至资料截止日最近可核实的记录。更新或复用报告时，重新核实会随时间变化的判断。

## 核验与登记来源（A1）

在[报告模板](../assets/report-template.md)的 A1 为可用来源分配编号（`S01`、`S02`）。新增来源分配新编号，再次引用已登记的来源时沿用编号。撤下的编号保留空号。记录原始标题、发布者、原文链接或可用的本地文件、发布与访问日期、原文位置、证据用途和限制。本地文件可用 Markdown 链接登记，路径相对于源稿。原文位置可用章节、页码、表行、字段或时间戳。搜索摘要、聚合页和机构主页用于定位原文。打不开原文时，记录实际可查的材料和访问限制，并相应限定判断。

A1 来源栏使用 `发布者：名称；发布：YYYY-MM-DD；访问：YYYY-MM-DD`。发布日期无法确认时填 `发布：未知`。网络来源填写实际访问日期，离线固定记录无需访问日期时填 `访问：不适用`。影响判断的统计期间或观察日期另行注明。

按原始记录判断独立性。转引材料注明原始出处，已登记时引用其编号，同一新闻稿、数据或采访的重复转述按同源处理。使用 `independent`、`shared-origin`、`mixed` 或 `unknown` 记录关系。样本、利益关系和统计限制单独说明。

核对来源实际记录了什么。公司公告可确认公告中的说法；实际交付、使用或经营影响各需对应记录。社区帖、用户评论和单个 issue 可作为个案证据，引用时说明样本边界。引用事后回忆时标明其性质，核实当事人当时的动机或行动时另查同期记录。

## 建立关键判断（A2）

只为影响核心结论的判断分配 `C01`、`C02` 等编号。每条写清对象、范围和结果，把关键事实或过程环节连接到具体来源及位置，并标明支持材料之间的独立性。修订同一判断时沿用编号，新设或拆出的判断另行编号。正文关键事实和关键判断紧邻 `[S01]` 等来源编号。构建器将编号链接到 A1，原文链接和定位保留在 A1。

按句子实际主张的内容确定证据门槛。兼有事实、因果或预测的判断，拆开核证，或按其中最严格的要求处理。有关市场的因果判断使用 `causal`，有关市场的作用过程使用 `mechanism`。

| 类型 | 最低要求 |
|---|---|
| `fact` | 原始记录直接覆盖所述事实。找不到原始记录时，用相互独立的可靠来源核验。 |
| `market` | 指标、样本、适用范围与判断相符。估计总体时核对样本代表性和统计口径。 |
| `causal` | 核实先后、行动和作用环节，比较主要替代解释，限定可归因的结果。 |
| `mechanism` | 写清中间环节和成立条件。案例运行查过程记录，理论机制查假设、推导或可重复实验。 |
| `forecast` | 明确预测范围和期间，给出变量、基准路径、替代情景、触发信号和会改变预测的观察。 |

`causal` 和 `mechanism` 分别填写 `过程：已观察、仅有理论支持或仍未知的环节` 与 `归因：证据能解释的结果范围及尚未区分的解释`。分别核实过程是否发生、它能解释多大范围的结果。

## 评定判断置信度

按证据支持判断的程度定级，核对来源是否同源以及是否覆盖主张范围。

| 等级 | 判定依据 |
|---|---|
| `high` | 直接、可核实的证据覆盖主张，足以改变结论的反向证据已核清。单一权威原始记录可支持其直接记录的事实。 |
| `medium` | 证据可靠，仍有重要缺口、来源独立性不足或尚未排除的主要替代解释。 |
| `low` | 主要依据线索、同源转述、对当前问题已过时的材料或未验证推断。正文限定为待核实信息或暂定解释。 |

A2 末栏使用 `置信度：high/medium/low；缺口：具体缺失或无重大已知缺口；修订条件：会改变本条判断的证据`。

## 处理冲突和反证

遇到相互冲突的记录，先核对是否指同一个对象、事件或指标，再核对时间、地区、样本、单位和分母。能够对齐时按同一口径复算，记录公式和输入。口径相同但结果仍有冲突时，追查原始记录、统计方法或修订版本。分歧无法解决时并列差异及其影响。把仍会影响结论的冲突和资料缺口写入 A3。

为核心判断查找最有力的反向材料或替代解释。可从同期更正、失败或回退、不同样本和竞争方案找线索。比较各解释预期看到什么，以及实际记录能区分什么。可以同时成立的因素分别核查作用范围。在 A2 记录实际查过的材料或主要检索词、发现和剩余疑点。用「在已查范围内暂未发现」表述反向检索结果。

## 回源核查成稿

逐条回查标题、摘要、关键判断和数字。用 XYZ 表定位每条核心判断对应的 A2 记录及 A1 原文位置，核对正文和 A2 是否准确反映证据可支持的范围，核对数字的期间、单位、币种和口径，复算派生数字，确认反证和限制已在相关结论旁体现。发现缺口时继续补查，并同步更新正文和账本。

关键判断均已回源核查、主要替代解释已检查后，按证据支持的强度收束。证据有缺口时，限定判断、写成待验证解释或移出正文，在 A3 交代仍会影响答案的限制和原研究问题中尚未解决的部分。用[结构校验脚本](../scripts/validate_report.py)检查字段和引用关系，用回源审计确认事实与论证。
