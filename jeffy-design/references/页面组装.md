# 页面组装与验收

主流程见SKILL.md。本文件只说明绘制规则、实现接口与验证边界。

## 绘制规则

- 数据与实际文字决定几何。字体加载后测量，不整体缩放预览来降低字号；容量不足交给模型调整区域、重排、换表达或分页。
- 表格表头、单元格与数字居中。独立模块无说明时标题水平垂直居中，有说明时标题与说明左对齐；层带名称按其结构角色处理。
- 连线标签和可见节点说明使用 assets/共用/line-labels.js 透明遮线，字号、布局或动画帧变化后重算，不用实色背景块遮盖。
- 图例与真实系列的名称、符号、线型和重点一致，底部居中分散排布；空间不足换行或反馈容量。沿用当前路径的共用布局器，不在每页复制算法。历史单图使用 assets/共用/legend.js，theme-v1使用ThemeDrawing.legend；二者尚未完全合并。
- 数据驱动轴范围、零线、刻度、精度及百分比。柱图从零起，零总量显示无占比；比较任务需要同尺度时保持一致。左右纵轴标题均竖向居中，预留真实刻度与标题宽度。柱图轴端为外侧半箭头，横向指标与单位在末刻度下方右对齐。
- 图表标题按绘图区中心定位，方向切换后重算。交互选项在顶部展开，不藏在下拉菜单里。
- 交互动效沿用约760ms、四次缓出；轴线与文字持续可见，无闪白，快速切换从当前几何接续。可选说明切换不拉伸画幅，减少动态模式直接显示完整终态。静态成页不宣称支持这些动效。

## 静态区域组装接口

输入根对象为 theme、pages。每页保留 id、title、question、claim、readingOrder、source、speakerNotes、components，及可选 text、bindings。它们是制作记录，不要求用户填写。区域构图与选材理由可放在已有记录中，不新增强制数据字段。

components 项为 id、material、purpose、data、box:{x,y,width,height}、options。text 项为 id、text、role、box。坐标相对所选主题 page.canvas，主体必须位于 page.content 内。theme-v1按元素语义使用主题角色，不接受任意labelRole或私加字号。组件标题由独立主题文字区域承担，非空data.title会明确返回UNSUPPORTED。

bindings只核对显式字段相等，不理解别名或所有语义对应。例如：

```json
{"id":"buyer","members":[{"component":"trade","field":"nodes.1.title"},{"component":"money","field":"nodes.1.title"}]}
```

响应包含 ok、issues、required、actual、regions、result；部分路径提供plot。regions记录实际文字尺寸。旧路径图形required仅为估计，不是精确最小区域。

错误类型：DATA非法数据；CAPACITY空间不足；LAYOUT碰撞；BINDING对应不一致；THEME主题配置或角色不符；FONT缺字体；UNSUPPORTED未实现；CONTENT缺内容说明；CONTRACT结构错误。不吞错误、不缩字通过。UNSUPPORTED表示当前代码能力，不是表达规范禁止，可按规范自定义绘制并验收。

```sh
node scripts/build-composition.mjs input.json output.html
node scripts/verify-page.mjs output.html validation.json
```

输出独立HTML及同源讲稿。当前12项常规适配器见 lib/composition/adapters.json，使用theme-v1；3项草稿尚未适配克莱因蓝，仅保留独立预览，区域构建会明确返回UNSUPPORTED。REL-001是root/children接口，不支持所有分层表达。跨主题范围见[主题自适应](主题自适应.md)，共享轴组合另见[页面描述](页面描述.md)。

## 验收证据

1. 内容：核对数字、单位、分母、来源、条件、归属与标题依据。
2. 组件：核对编码、数据与关系完整性、标签图例和缺失处理。
3. 画面：在最终画布测量主题字号、对齐、遮线、越界和碰撞；自定义页面也须检查。
4. 表达：隐藏讲稿，沿阅读顺序复述关键关系，指出结论依据。再按主题writing朗读，检查是否自然直接。

保存实际观察与对应截图，自动检查、人工读图和用户评价分别记录，不互相替代；改稿后重新验收受影响部分。交互另外核对终态、中间帧、连续切换与减少动态。每份记录只证明所覆盖的输入、主题与实现。

区域设计参考：[攀岩市场三页](../examples/climbing-market/index.html)。复用其设计过程，不把三页布局固化为模板。该案例经过同一模型自审和用户整体认可，非独立盲测。
