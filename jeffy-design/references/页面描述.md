# 柱线同绘图区工具

仅在柱图与折线需要共享绘图区、坐标轴时使用。此工具保留固定的整页与chart-notes布局，尚未迁移theme-v1的page空间与完整主题接口。需要自由区域设计时使用区域组装或依规范自定义，不让固定工具反向决定内容。

## 输入

根对象theme、pages；每页含id、title、source、speakerNotes、data、chart。

data.categories是唯一有序类别；data.values按字段提供等长数值数组。chart.series指定type(bar/line)、field、name、unit、axis(left/right)；折线可选mode(raw/cumulative/index)、shape(linear/step)。chart.axes.left/right指定title、includeZero及可选min/max。

同轴同单位，数据按相同类别和统计口径对齐。柱接收有限非负值且从零起；折线null代表缺失，累计遇缺失保持未知，指数基期须非零。模型负责组合含义，不因同图就推断因果。

layout.kind=chart-notes时，explanation提供title/body，table提供columns/rows。区域按工具固定，不能任意嵌套；容量不足返回CAPACITY。其他错误含UNIT、RANGE，不能缩字或无限增大画布规避。

## 构建与检查

```sh
node scripts/build-page.mjs pages.json output.html
node scripts/verify-page.mjs output.html validation.json
```

生成独立HTML与同源讲稿，浏览器检查比例尺、点位、文字碰撞与越界；失败返回非零。构建成功不代表内容或表达已通过。旧版记录含本机路径，不作为可复现入口；以当前输入和最终输出重新验证。
