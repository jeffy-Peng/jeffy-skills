# 统一页面描述与生成接口

当前覆盖单系列/分组柱、普通/阶梯线、累计/指数线及同绘图区组合。其他既有素材暂按原入口使用，后续逐项迁移。

## 页面输入

根对象 theme 指定 themes/ 中主题，pages 是页面数组。每页含 id、title、source、speakerNotes、data、chart。

data.categories 为唯一有序类别，data.values 按字段保存等长数值数组；组合的数据须在研究阶段对齐相同月份与统计口径。

chart.series 定义 type（bar/line）、field、name、unit、axis（left/right）。折线可选 mode（raw/cumulative/index）、shape（linear/step）。chart.axes.left/right 定义 title、includeZero 和可选 min/max。

同轴须同单位。柱目前支持有限非负值且从零起。折线缺失用 null，累计遇到缺失后保持未知；基期指数首值须非零。组合语义与指标相关性由模型判断。

## 固定画布布局

页面为1280×720。模型提供组件、数据绑定与共享轴；统一核心处理主题角色、比例尺、图例、轴标题、类别位置及文字空间。标题和来源各有独立区域，左右轴标题均竖向居中；底部图例测量后居中分散，换行所需高度由绘图区让出。

容量不足返回 CAPACITY，单位冲突返回 UNIT，范围问题返回 RANGE。模型根据具体原因改变内容、图型或组合。禁止用无限增大画布代替成页排版。

原柱、线视觉约定迁入统一绘制核心，新入口不再复制两张完整 HTML 后移动图形。原组件预览继续作为设计参照。主题以所选 JSON 为准，当前验证两个已存在主题。

## 构建及验收

在 Skill 根目录运行：

~~~sh
node scripts/build-page.mjs pages.json output.html
node scripts/verify-page.mjs output.html validation.json
~~~

第一条生成包含数据、主题和运行代码的独立 HTML，以及同源 .notes.md。第二条在浏览器运行，检查数据约束与主题字号下文字碰撞、越界，并记录比例尺及各点坐标；失败返回非零退出码。

构建成功代表文件写出，浏览器检查通过后再交付。语义、视觉观感、复杂动效另行审阅。

可复现输入在桌面“统一页面引擎验证”，含两主题×三形态、右轴负数、小数、全零及单位冲突、容量不足案例。当前是经过验证的首批分支，不代表其余素材已迁移。

## 可复现起点

桌面“统一页面引擎验证/klein-blue.json”是一份完整输入：同一数据分别生成单柱、单线与柱线组合。修改 theme 后重建可切换主题；修改 chart.series 即可改变组合。具体逐页验收记录保存在同目录 *.validation.json。

## 图表与说明的分区验证

layout.kind = chart-notes 时，在固定画布内给图表、右侧解释及下方表格预留区域。explanation 为 title/body 数组，按主题字号测量换行；table 为 columns/rows，核对列宽及预留高度。说明或表格装不下时返回 CAPACITY。当前为首个分区布局，尚不支持任意拖拽坐标或自由嵌套。

实测输入在桌面“高密度页面难题验证”：两主题下订单、客单价、退款比例与净收入的同页解释，以及故意超量的内容反馈。

## 多组件区域调用

柱线同绘图区仍使用本接口；黑白灰多区域素材组装新增[组件调用与四关验收](页面组装.md)，使用 build-composition.mjs。两者覆盖范围分别声明；新入口不代表所有旧素材已迁移。
