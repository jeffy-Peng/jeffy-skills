# 表达选择测试题

不规定唯一版式。先只看题目选择表达，再按下列标准检查；本轮为测试集建立，尚未做独立模型盲测。

1. 一份请求在申请人、审核人、执行人间交接，拒绝后返回补充。检查是否保留责任归属和返回条件；泳道通常合适，普通时间线不足以表达责任。
2. 客户端请求平台，平台查询外部系统，外部系统返回，平台再响应客户端。检查消息顺序、发送接收方及返回；时序图通常合适，单向流程会遗漏往返。
3. 产品包含入口层、业务层和基础能力层，各层有多个模块。检查归属、层名、模块；分层结构合适，不能将上下层直接当执行先后。
4. 处理时间数据齐全，还要解释跨角色交接。允许泳道与条形比较组合，但必须对应同一环节；没有耗时证据时不编造柱图。
5. 同一对象从草稿变成已提交，再进入通过或退回。检查状态与触发条件；不能用时序图替代状态机。

每题核对：关键内容是否完整；图形语义是否正确；组件是否各有任务；能否从页面指出标题依据；是否有可删除的重复表达。记录选择理由和未表达的边界，不仅判断是否命中某个素材ID。
