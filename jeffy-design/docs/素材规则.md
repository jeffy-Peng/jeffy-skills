# 素材共同规则

规则清单由 `lib/composition/contract.json` 生成。它记录语义要求与验收目标；标为已检查只表示有代表用例，不保证任意结构均已覆盖。不得通过改数据、缩主题字号、丢对象来让画面通过。

制作顺序、默认交付和确认方式只以 [SKILL.md](../SKILL.md) 为准。主题负责视觉数值，素材负责编码与关系，形态选择不改变数据含义。

## 执行入口

- 输入与调用：读取对应 `assets/materials/<ID>.md`。规范允许的表达可能超出现有工具范围；明确返回 UNSUPPORTED 后可按规范重绘，不能丢数据。
- 字体、颜色、间距、区域、线宽：[主题自适应](../references/主题自适应.md)。不把某套主题的像素值写成全库硬规则。
- 对齐、轴、图例、遮线与整页检查：[页面组装](../references/页面组装.md)。表格一律居中；形状文本整体垂直居中。
- 类型与视觉形态：[素材使用与维护](../references/素材使用与维护.md#两步选材与调用)。同一 ID 的形态显式选择，方向与数量自动适配。
- 聚焦、键盘、触屏、静态导出：[交互规则](交互规则.md)。聚焦与形态切换是不同能力，不能凭文档宣称所有图都有切换动效。

## 验收边界

自动检查覆盖字段、代表数据、字体角色、实际边界与部分几何关系；事实、口径、因果关系、视觉误导仍需人工审阅。容量不足先重排、调整区域或换表达，不按固定类别数机械删减或抽样。

图例由当前绘制接口统一处理：数轴图表经 KitLegend，饼图等经 ThemeDrawing.legend；两者的测量、符号和排布应共用同一底层布局逻辑。默认底部居中，单系列可省略；完整名称放不下应反馈容量，不能截断。
