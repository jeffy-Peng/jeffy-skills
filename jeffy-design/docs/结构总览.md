# 结构总览

- SKILL.md：唯一制作流程，受众与问题 → 内容证据 → 区域设计 → 选材绘制 → 讲稿 → 验收。
- themes/*.json：视觉、色板、区域；docs/写作规则.md：文本风格。
- assets/materials/*.md：素材规范与机器声明，是条目登记来源。
- assets/catalog.json：同步后的目录，保留审批和行为证据等补充字段；不在此增删规范条目。
- lib/constants.mjs、lib/browser.mjs：项目级单一常量、主题加载与 Playwright 统一入口。
- lib/theming/：统一色彩（color.js）、测量、主题解析（resolve.mjs）、绘制（drawing.js）与按图形家族拆分的渲染器（renderers.js + renderers/*.js）；lib/kit/：轴、图例、单位、布局、遮线。
- lib/composition/：运行时脚本清单与 HTML 组装（bundle.mjs、build.mjs）、页面运行时（runtime.js、interaction.js、fatal.js）与共用契约（contract.json）；lib/checks/：实际 DOM 验收与报告核查（page-checks.mjs、verify.mjs）。
- scripts/sync.mjs：从声明生成能力、允许参数与适配器；--check 不写文件，有差异即失败。
- scripts/gen-rules.mjs：从 contract.json 同步 docs/素材规则.md；--check 只检查。
- scripts/test-architecture.mjs：可执行架构守卫（SSOT 对齐、无循环依赖、模块边界、无冗余载荷）。
- scripts/build-composition.mjs：支持引擎、模型 SVG、外部图片和纯文字页面，输出 HTML 与讲稿。
- scripts/verify-page.mjs：渲染与覆盖检查；失败、空报告、零测量不能通过。
- scripts/check-notes.mjs：数量单位和显式事实绑定，语义仍需审阅。
- scripts/visual-baseline.mjs：从当前代码重画引擎样张，与已批准基线比较；只在 --update 时写基线。
- assets/skeletons/、assets/pages/：参考快照，不声称经过当前源码自动回归。
- build/：忽略的构建与测试产物；实际测试规模读取报告，不手抄固定计数。

维护后运行 npm run sync、npm run test:all；绘制层修改另跑 npm run baseline 并审查漂移。最终交付件嵌入字体后重新渲染验收。
