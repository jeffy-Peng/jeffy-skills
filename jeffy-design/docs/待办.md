## 动效（已定方案，暂不动手）

lieflat 的六种入场动效与参数：

| 动效 | 参数 | 用途 |
| --- | --- | --- |
| 缩放弹入 pop | 500ms，cubic-bezier(.2,.7,.3,1.3)，回弹约 3% | 饼的扇瓣、散点 |
| 淡入 fade | 900ms ease | 大块面、卡片 |
| 描线 draw | 1000ms，cubic-bezier(.4,0,.2,1)，stroke-dashoffset 推到 0 | 折线、连接线、流带 |
| 条形逐根 | 每根延迟 100ms（80–130），升 700ms | 柱状、堆积、条形 |
| 点阵逐点 | 每点延迟 12ms（8–15），出现 380ms | 点阵饼、散布 |
| 分组错峰 | 组内 40ms、组间 140ms | 多系列 |

落进本 skill 需要三处：

1. 主题加动效字段：入场时长、曲线、逐块延迟、默认开关。
2. 运行时渲染完成后挂 IntersectionObserver（阈值 0.3），按素材类型选动效，点击可重播，重播前清定时器。
3. 冻结开关：导出 PNG 与基线比较必须跳过动效直接给终态，否则截图拍到中间帧，基线全报差异。

动效与信息的关系：柱、饼、折线有信息量（顺序、方向、占比），表格与热力矩阵不加动效。

原型见 `pie2-motion.html`（临时目录），已用 PIE-002 试过扇瓣张开 + 标签浮入。
