# 素材共用能力清单

所有素材共用一套，写在 `lib/composition/contract.json`。素材只声明支持哪些，不各自实现。

下面按输入、结构、视觉、输出、追溯五组列，每项标现状：已统一、部分、还没做。

## 一 输入

数据形状。items 与 series 两种，类别、值、可选系列名。部分，各渲染器自己校验。

必填与可选字段。必填是 label 与 value 或 values，可选是 series、unit、metric、title。部分。

缺失值。null、空字符串、缺字段怎么处理，目前没有统一规定。还没做。

数字。负数、零、小数、四位以上千分位怎么写。部分。

单位与百分比口径。单位标在哪里，百分比的分母是谁。还没做。

重复类别名。两条同名类别是合并、报错还是加序号。还没做。

极值。单个数据点、全零、全负。部分。

数量上限。超过可读尺寸建议分页，不硬画。还没做。

## 二 结构

方向。竖排或横排，只对适用素材。已统一。

排序。按给定顺序、按值降序、按值升序。还没做。

模式。绝对值或百分比。部分。

形态。单系列、并置、堆叠、瀑布。部分。

系列顺序。图例顺序必须和绘制顺序一致。部分。

## 三 视觉

字号与颜色只能取主题角色。已统一。

间距、内边距、圆角、线宽来自主题。已统一。

笔触按族由主题指定。已统一。

字体族来自主题，缺字体报 FONT。已统一。

## 四 输出

容量反馈。放不下报 CAPACITY，附需要多少和实际多少。部分。

错误码。DATA、CAPACITY、LAYOUT、THEME、FONT、UNSUPPORTED、CONTRACT、CONTENT。部分，目前靠约定。

不静默降级。不缩字号、不丢数据、不省标签。部分。

最小可读尺寸。柱宽八像素、行高二十二像素、点距十六像素、表格行二十四像素。部分，柱状已落地。

文字区域回报。把实际位置与字号交回验收。已统一。

可访问性。图形要有 role 和 aria-label。部分。

## 五 追溯

素材 ID、来源、验收记录与输入绑定。部分。

## 现状总结

真正已统一的只有视觉那一组和方向、文字区域回报。其余大半是各渲染器各写各的，靠测试兜住结果，但没有统一规定过程。

## 接下来按这个顺序补

第一，输入校验器。缺失值、重复类别、数字格式、数量上限，一次写完所有素材共用。这块最容易被真实数据踩到。

第二，排序与系列顺序。写进契约，柱状和折线先接，其余族按需。

第三，单位与百分比口径。统一标注位置和分母定义。

第四，可访问性与追溯。图形有 aria-label，验收记录带上素材 ID 和输入哈希。

前两项做完，加素材才能真正只写声明，因为数据校验和排序都不用再写一遍。
