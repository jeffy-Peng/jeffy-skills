# 维护说明

给三个月后的自己和接手的人看。所有命令都在 skill 根目录执行。

## 数据驱动：只改数据和声明

两条路都不用碰脚本。

**加主题**：在 `themes/` 放一个 JSON，跑 `npm run sync`。测试会自动覆盖新主题，`verify-page` 的默认主题也跟着变成排序后的第一个。

**加素材**：在 `assets/catalog.json` 里加一条，写清 `archetype`（compare / trend / share / table / timeline / relation / flow 之一）。跑 `npm run sync`，登记表、能力表、目录、测试清单一起长出来。没有 `archetype` 的素材算「仅规范」，不会被装配。

`node scripts/sync.mjs --check` 只检查不写，用来确认生成物和声明一致；`npm test` 和 `build-composition` 都会先跑这一步，声明改了没同步会直接停。

## 回来先跑一条

```sh
npm run doctor
```

七项自检，缺什么自己装：Node 版本、Playwright 模块、Chromium、主题字体、字体子集工具、生成物一致性、验收冒烟。跑完显示 `7/7 项就绪` 就可以直接开工。加 `--no-install` 只看不修。

## 三件事最常见

**换一份稿字体的机器上跑不起来**
`bash scripts/install-fonts.sh`。字体来源、版本和 sha256 在 `scripts/fonts.lock.json`，改字体版本就改这里，别只换文件。丢字体的表现是画布正中一张蓝色边框的报错页，写着缺哪个族名。

**交付给客户前要自包含**（脚本走 `scripts/subset-font.py`，会保住原字体的升降部，否则 14.5px 的字会被撑成 18px 高）
`node scripts/embed-fonts.mjs 稿子.html 稿子.embedded.html`。把用到的字挑出来做 woff2 子集，塞进 HTML，默认预算 3MB，超了报错。发出去之前用 `node scripts/verify-page.mjs 稿子.embedded.html` 再验一次。

**写提纲时先卡住**
`node scripts/validate-outline.mjs 提纲.json`。每页要 id、title、question、claim、readingOrder、speakerNotes、source，缺了报 CONTENT；选了没有适配器的素材报 UNSUPPORTED 并列出当前可用的 12 项。

## 校验脚本各管什么

| 脚本 | 作用 | 通过的样子 |
| --- | --- | --- |
| `scripts/doctor.mjs` | 环境自检与自修 | `7/7 项就绪` |
| `scripts/verify-page.mjs` | 渲染验收，页面报告加整页检查 | `3/3 页通过，整页检查 3 页无问题` |
| `scripts/visual-baseline.mjs` | 素材示意图与页面骨架图的像素基线回归，超千分之三报漂移 | `same` |
| `scripts/test-material-contract.mjs` | 按契约自动生成用例，跑全部可组装素材 | `39/39 个契约用例通过` |
| `scripts/validate-outline.mjs` | 提纲校验，素材能力校验 | `提纲通过：N 页` |
| `scripts/check-notes.mjs` | 讲稿与画面数字比对 | `数字一致：N 页` |
| `scripts/embed-fonts.mjs` | 字体内嵌 | 打印体积与每个字体的字节数 |
| `scripts/font-metrics.py` | 把探针文字的字宽写入 `fonts.lock.json`，渲染时比对 | 三个字体各打印一行 metrics |
| `scripts/subset-font.py` | 子集化并保留原始纵向度量，`embed-fonts` 调用它 | 生成 .woff2 时不报错 |
| `scripts/build-catalog.py` | 生成 Catalog 与 `assets/capability.json` | `References and preview dependencies valid` |

`verify-page` 的三类结论要分开看。页面报告（`pages`）来自装配层，看的是组件放没放下；`audit` 是整页检查，手画的页也过同一套，看字号是否在主题阶梯、字体是否命中族名、文字是否越界、同一角色跨页是否同字号、同页线宽是否统一；退出码 2 表示渲染都没起来，先看报错页上写的原因。

## 加一个素材

1. 先确认不是已有素材换个方向。写 `assets/materials/<ID>.md`，五节正文：语义、绘制、可调整、不适用、验收。
2. 头部机器字段写清 `archetype`（几何族）、`shape`（数据形状）、`tier`、可接受的 `options`、最低数据。
3. 同族已有几何就在 `lib/theming/renderers.js` 加分支，不要另起一套；用 `ThemeDrawing.create()` 的角色和测量接口，不写裸字号。
4. `npm run sync` 生成登记、能力表与目录，`npm run test:materials` 跑契约用例。
5. `npm run specimen <ID>` 出 `assets/materials/specimens/<ID>.png`，再 `npm run baseline` 建基线。
6. 尺寸相关的值写成比例加夹取，不写固定像素。柱宽就是这么处理的：槽位一半，夹在 8 和槽位八成之间。

## 模型绘制的素材

19 条素材没有代码实现，头部写 `implementation: model`，不进适配器、不进基线。模型按 md 的绘制与验收一节直接画，验收只查数据是否完整、文字是否越界或碰撞，不查像素。

要让某条转成引擎实现：在 `renderers.js` 加几何，把 md 的 `implementation` 改成 `engine`，跑 `npm run sync` 和 `npm run specimen <ID>`，再 `npm run baseline:update` 建基线。

## 页面骨架与版面

六种页面在 `formats.slide.types`，每种声明区域和是否要页眉线、页脚。内容页与附录写 `use: "page"`，引用主题 page 的区域，不复制坐标；改了主题 page，这两类页面自动跟着变。

封面、转折页、目录、结束页各写自己的坐标。它们没有组件，构建和装配里所有读 `components`、`readingOrder` 的地方都按空数组处理。

版面参数在主题里。`grid` 是基线 8、四栏、栏距 24，间距只用 8、16、24。`density` 是组件数量上限，稀疏 1、常规 2、密集 3，不限制占用比例。结论行由 `lib/kit/layout.js` 按实测文字宽度算行数，页面不得手写高度。

改完骨架重出 `assets/skeletons/` 对应那张，跑 `npm run baseline`。漂移是预期的就 `npm run baseline:update`；不是预期的，说明几何被副作用改了，回去查。

## 加一个主题

只加 `themes/<名字>.json`，不要复制素材。视觉参数、字号阶梯、可用区域、写作提示都在这一个文件里。加完 `node scripts/test-themes.mjs build/theming`，再拿一份真实输入实际渲染读图。`verify-page.mjs` 的第三个参数可以指定主题名。

## 工程约定

- `lib/theming/renderers.js` 是唯一的绘制实现。构建期不再从素材示例里切代码，素材里的示例文件只作参考样张。
- 字号只从主题角色取，任何地方出现裸字号都会被 `verify-page` 的整页检查标出来。
- 族名能命中不等于用的是那个文件。Noto Serif SC 和系统里的 Noto Serif CJK SC 名字相近、宽度差约 3%、行高差 2px，渲染时会按 `fonts.lock.json` 的探针字宽再比一次，偏了报 FONT 并说明「安装的是同名替代字体」。改了字体版本就重跑 `npm run font-metrics`，否则会误报。
- 内嵌子集只做族名检查，不做字宽比对：子集按本页字符裁过，度量与整字体有微小出入。
- 新增检查项就加到 `lib/checks/page-checks.mjs`，不要在脚本里另写一套。
- `lib/composition/adapters.json` 和 `assets/capability.json` 是生成物，不要手改。
- 提交前 `npx prettier --check "lib/**/*.{js,mjs}" "scripts/*.mjs"`。
