# 素材实现方式判定

19 条模型绘制素材逐条过。判断三条：出现频率、几何有没有唯一正解、数值比例要不要严格对得上。三条都成立就转引擎；有一条不成立就留模型加 md 约束。

## 一 建议转引擎（13 条，全部完成）

第一批五条（BAR-005、BAR-007、DIST-001、MATRIX-001、REL-004）与第二批八条（FUNNEL-001、HEAT-001、TIME-002、RADAR-001、REL-003、SCATTER-001、BOX-001、SANKEY-001）都已转成引擎实现。


| 素材 | 理由 | 复用 | 工期 |
| --- | --- | --- | --- |
| BAR-005 正负柱 | 零基线加方向，几何唯一，属于柱族 | 直接改 `bars()`，加零基线分支 | 半天 |
| BAR-007 目标对照柱 | 并排两柱加差距，和分组柱同构 | 复用 `bars()` 的分组 | 半天 |
| DIST-001 直方图 | 分箱之后就是柱，箱宽箱数可算 | 复用 `bars()` | 半天 |
| MATRIX-001 四象限 | 两轴加散点加分界，几何确定 | 复用散点 | 一天 |
| REL-003 包含关系 | 外框加内块，纯布局 | 新写，四十行 | 半天 |
| REL-004 分层架构 | 层框铺满，模块均匀，纯布局 | 新写，五十行 | 半天 |
| RADAR-001 雷达图 | 轴数有上限（八），极坐标固定 | 新写，六十行 | 一天 |
| HEAT-001 热力矩阵 | 单元格填色按值归一，规则完整 | 复用表格的网格 | 一天 |
| TIME-002 甘特条 | 行加时间轴加条带，轴可复用 | 复用 TIME-001 的时间轴 | 一天 |
| FUNNEL-001 漏斗 | 条长按比例，阶段间写转化率 | 新写，五十行 | 一天 |
| SCATTER-001 散点 | 两轴加点，密集时降不透明度 | 复用折线的轴 | 一天 |

## 二 建议留模型（6 条）

| 素材 | 留的理由 |
| --- | --- |
| REL-002 交换关系 | 主体数量两个到四个不等，排布随内容变，一年用几次 |
| REL-005 中心辐射 | 外围节点数不定，多了要避让交叉，接近力导向布局 |
| LOOP-001 循环图 | 环节数不定，说明写在弧外，字数差异大，排版每次要判断 |
| SEQ-001 时序图 | 参与者与消息数不定，消息密集时要错行，属于布局问题 |
| SET-001 集合图 | 三个以上集合的相交位置没有唯一解，画出来容易误导 |
| FLOW-002 泳道图 | 泳道乘步骤的网格加跨道连线，等于半个布局引擎，收益不抵成本 |

判定依据：几何随内容剧烈变化，写死一套只会得到「能跑但难看」，模型每次按内容排反而更稳。

## 三 分批顺序

第一批（三天，都在已有几何上加分支）：BAR-005、BAR-007、DIST-001、MATRIX-001、REL-004。这五条覆盖日常最多，且复用现有代码，风险最低。

第二批（四天，新几何）：FUNNEL-001、HEAT-001、TIME-002、RADAR-001、REL-003。

第三批（三天，复杂的）：SCATTER-001、BOX-001、SANKEY-001。桑基要先定透明度那条冲突，箱线要先定分位数算法。

## 四 转之前要补的两条规则

**分位数算法**。箱线图必须写死一种，否则同一组数两次画出来箱体不一样。建议用「最近秩法」，并在图注写明。

**色阶与缺失**。热力矩阵要沿用已有的明度阶梯规则，缺失格必须视觉上不同于最浅一档，现在规范里只写了「缺失格留白」。

## 五 暂不做的

19 条里转了 13 条，剩 6 条留给模型。引擎实现有持续维护成本：现在 26 条，两套主题就是 52 次回归。留 6 条给模型，是给「一次性怪图」留出口。
