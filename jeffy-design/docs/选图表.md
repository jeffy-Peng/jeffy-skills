# 选图表

按「数据形状 → 素材 → 编码 → 阅读时间」排。选型先认数据形状，再看场合与阅读时间，最后看替代关系。

先按内容关系选素材 ID，再读取 Catalog 中该 ID 的 variants，结合用户指定、主题用途、空间与读数要求选形态。执行上下文、参数和冲突处理见[两步选材与调用](../references/素材使用与维护.md#两步选材与调用)。
