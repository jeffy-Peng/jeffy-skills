# 新增主题

当前维护 simple-line，色板为 klein-blue 与 mono。只换配色时增加 palette，不复制素材或主题。

新增设计语言时在 themes/<name>.json 声明 usage、fonts、scale、colors/palettes、rules、materials、brush、grid/density 和 formats.slide.types。具体接口见 references/主题自适应.md，字段校验由 resolve.mjs 负责。

先确保真实字体和测量可用，再用代表数据实际重排。已有接口能表达的只改配置；新风格需要新画法时扩展共用绘制层，不能只声明一个没人读取的参数。写作规则仍在 docs/写作规则.md，不随视觉主题复制。

运行 sync、test:all，检查正常输入、容量不足、缺字体和缺配置。引擎素材通过后先查看当前源码样张，再显式 baseline:update 建立该主题的批准基线。verify-page 的第三个参数指定主题名。

新主题不意味着所有输入与结构都能容纳；最终材料仍要按其内容重新渲染、读图和审阅。
