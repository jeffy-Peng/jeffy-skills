# Theme · 主题目录

用户指定优先；无指定默认 klein-blue。先确认受众、场合与格式，再读取主题JSON内的 usage、page、writing 和视觉参数。场景为使用建议，不是已通过相应场景验证的声明。

| 主题 | 适用场景 | 文本与讲稿语气 |
|---|---|---|
| [克莱因蓝](klein-blue.json) · 默认 | 研究分析、市场概览、产品与商业机制讲解 | 有依据、有深度，中文直接自然，讲稿像向同事解释 |
| [黑白灰](mono.json) | 内部讨论、方法讲解、素材审核 | 简洁客观，减少修饰 |
| [墨黑·靛蓝](ink-blue.json) | 经营汇报、业务评审、方案说明 | 具体结果、原因与影响 |
| [墨黑·朱红](red-ink.json) | 重点事项汇报、复盘、决策讨论 | 明确克制，突出证据与条件 |
| [纸白·墨黑](paper-ink.json) | 知识分享、概念课程、叙事研究 | 循序解释，温和清楚 |
| [圆角无衬线黑白灰](rounded-mono.json) · 测试 | 跨主题回归 | 中性，明确测试边界 |

每套主题JSON是其视觉、空间与写作要求的维护源，不再另写一份重复提示词。writing供模型读取，不是自动文字改写器；page定义过程页可用区域，不限定主体布局。主题自适应与维护见[说明](../references/主题自适应.md)。

当前提供配置级主题；起始、目录、过渡、结束四类样张尚未齐备。静态区域适配器验证了mono、klein-blue、rounded-mono，其他配置需按实际输出验收。字体不打包，缺字体须停止并报告。
